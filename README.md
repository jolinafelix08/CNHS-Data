# CABIAO NATIONAL HIGH SCHOOL

## KPI-BASED STRATEGIC DASHBOARD

Jolina F. Gripal, MBA Candidate, Wesleyan University – Philippines

Capstone Project: Driving Institutional Performance Governance Through A KPI-Based Strategic Dashboard for Cabiao National High School
### Purpose

This dashboard was developed to provide school administrators with an integrated tool for monitoring institutional key performance indicators (KPIs), identifying performance gaps, and supporting data-driven management decisions.

### Dashboard Perspectives

1. Student Outcomes
2. Financial Management
3. Internal Operations
4. Stakeholder Engagement

### Period Covered

School Years 2023–2024 to 2025–2026

Fiscal Years 2023-2025
### Main Features

* Interactive filtering
* KPI summary cards
* Performance trend analysis
* Target and actual performance comparison
* Identification of performance gaps
* Prioritization of management issues
* Decision-support insights across key institutional areas

### Technology

The dashboard was developed using:

* HTML
* CSS 
* JavaScript 

### Supporting Data

The dashboard utilizes an Excel-based KPI dataset structured according to the selected institutional performance indicators used in the capstone project.

### Important Data Disclaimer

The data and information presented in this publicly accessible dashboard are provided solely for academic presentation, demonstration, pilot evaluation, and capstone defense purposes.

The values shown in the dashboard should not be interpreted as official, current, or actual operational records of Cabiao National High School. Where necessary, data were aggregated, anonymized, structured, or generated for purposes of demonstrating the functionality and decision-support capabilities of the proposed KPI-based strategic dashboard.

Any version intended for actual institutional use by Cabiao National High School should utilize validated school records and should be deployed through an appropriately controlled local or restricted-access environment.

### Academic Use

This repository forms part of the MBA capstone project entitled:

**“Driving Institutional Performance Governance Through a KPI-Based Strategic Dashboard Model for Cabiao National High School.”**

The dashboard is intended to demonstrate how institutional performance data can be consolidated, visualized, analyzed, and translated into actionable management information.
